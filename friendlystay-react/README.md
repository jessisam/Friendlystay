# 📱 FriendlyStay React Frontend

The frontend for FriendlyStay Homestay built with **React 19**, **TypeScript**, **Vite**, and **Vanilla CSS**.

![Website Preview](../docs/screenshots/website_preview.jpg)

## 🚀 Running Locally

```bash
npm install
npm run dev
```

For full-stack Docker execution, refer to the main repository [README.md](../README.md).
